## The learning loop

Goal → learn quickly → ask Gemini → discuss → apply → practice aloud → self-adjust.

Read one section, close it, and explain it in your own words. If you get stuck, ask a basic question. If it feels easy, take a harder case.

You control the pace. No required logs, scorecards, or daily state updates.
